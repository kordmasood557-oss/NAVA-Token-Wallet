# AMANAT — Trust and Accountability

## Purpose
This project aims to make charitable allocations transparent
and verifiable.

## Core Principles
- Clear documentation of token allocations.
- Publicly verifiable transaction history.
- No hidden changes to allocation rules.
- Charitable funds must not be described as locked
  until enforced by a tested smart contract.
- Security and independent review are required before deployment.

## Current Status
Documentation only.
No charitable funds are currently secured by this file.
