# NAVA Wallet Security Principles

## Current Status
This project is an early development prototype.
It is not ready for real funds.

## Private Key Protection
- Never commit private keys, passwords, or recovery phrases.
- Never send secrets through chat.
- Use established cryptographic libraries and audited standards.

## AMANAT Allocation
- Charitable allocations must be defined transparently.
- A written statement does not lock funds.
- Restrictions must be enforced by a tested smart contract.
- Contract rules and withdrawal authority must be reviewed before deployment.

## Testing
- Test on a blockchain test network first.
- Review security risks before any mainnet release.
